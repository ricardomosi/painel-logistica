# Anti-Slop Design & Enterprise Craftsmanship — Antigravity Guide

> Distinctive, intentional, human-crafted UI for enterprise tools, productivity apps, and modern web platforms.
> Replaces AI defaults, bloated spacing, and generic gradient clichés with crisp hierarchy, high density, and purpose-driven styling.

---

## 1. THE CORE PRINCIPLE: DESIGN WITH INTENT, NOT DEFAULTS

AI-generated interfaces suffer from recognizable patterns that scream "generated by an LLM":
1. **The Dark/Light Chimera**: Slapping a dark navy/black gradient box with neon text inside a clean white modal or page.
2. **Side-Tab Card Cliché**: A thick 4px-5px colored left border on a rounded card (`border-l-4 border-l-blue-500 rounded-2xl`).
3. **Cardocalypse**: Cards nested inside cards inside cards, each with 24px padding and diffuse shadows, wasting 60% of viewport space.
4. **Neon & Sparkle Overdose**: Random purple/cyan gradient buttons (`bg-gradient-to-r from-blue-500 via-indigo-500 to-cyan-500`), sparkle icons (`✨`), and pulsing fire icons on everyday enterprise buttons.
5. **Fake Crypto/Terminal Stat Widgets**: Giant dark containers with oversized circular icon badges and bright green/yellow monospace numbers for simple business totals.
6. **Airy Bloat over Usability**: Massive vertical padding (`p-8`, `py-12`) on data entry screens where users need to see their full dataset without endless scrolling.

---

## 2. THE 10 COMMANDMENTS OF ANTI-SLOP ENTERPRISE DESIGN

### I. High Information Density for Productivity
Enterprise and operations software (logistics, ERP, CRM, dashboards) are work tools, not consumer landing pages.
- **Compact Padding**: Use `p-3` to `p-4` for containers, `py-2` to `py-2.5` for inputs, and `py-2.5 px-3` for table cells.
- **Fit in the Viewport**: Modals and primary work areas must display their main forms and tables without forcing users to scroll past giant decorative banners.

### II. Single Cohesive Theme per Surface
- If a modal or surface is Light Theme (`bg-white`), **every child component, toolbar, and footer must belong to that light/neutral family** (`bg-slate-50`, `bg-slate-100`, `border-slate-200`).
- **BANNED**: Inserting a `bg-slate-900` or `bg-[#0B132B]` dark island in the middle of a white modal just to make a form "pop".

### III. Banned Clichés & Replacement Matrix

| AI Slop Cliché | Why It's Bad | Clean, Distinctive Solution |
| :--- | :--- | :--- |
| **Side-tab colored border** (`border-l-4 border-l-blue-500`) | Universal AI card template | Clean subtle border (`border-slate-200`) + clear icon or status tag |
| **Sparkle icons (`✨`) & Neon buttons** | Unearned hype on regular forms | Solid, professional brand CTA (`bg-blue-600 hover:bg-blue-700 text-white font-semibold`) |
| **Giant decorative banners in modals** | Consumes 120px+ of vertical space | Inline header with title on the left and action buttons on the right |
| **Dark crypto stat boxes with neon green/yellow numbers** | Clashes with enterprise UI | Clean, high-legibility summary cards in soft neutral tones (`bg-slate-50 border border-slate-200`) |
| **Over-rounded cards** (`rounded-3xl` on small tiles) | Blob-like feeling | Disciplined radius: `rounded-xl` (12px) for cards, `rounded-lg` (8px) for inputs |
| **Multi-colored rainbow inputs** (cyan, amber, purple borders on one row) | Visual noise & confusion | Consistent neutral borders (`border-slate-200 focus:border-blue-500 focus:ring-1`) |

### IV. Typography Hierarchy & Restraint
- Maximum 2 font families (one clean sans-serif for UI, one crisp monospace for codes/values if needed).
- Font sizes must have clear steps (e.g., `text-xs (12px)`, `text-sm (14px)`, `text-base (16px)`, `text-lg (18px)`).
- Never use undersized functional text below 11px for critical data or actions.

### V. Forms & Table Craftsmanship
- **Inline Action Bars**: Place filters, search, and quick-add inputs on a single cohesive, compact row.
- **Table Structure**: Sticky headers (`thead bg-slate-50 sticky top-0`), right-aligned numeric data, monospace numbers for currency and weights, clear visual row hover (`hover:bg-slate-50/80`).
- **Input Clarity**: Clean labels positioned directly above inputs with `text-xs font-semibold text-slate-700 mb-1`.

## 3. CHECKLIST BEFORE SHIPPING ANY UI

1. [ ] **No Artificial Dark Boxes**: Are all sections consistent with the page/modal theme?
2. [ ] **No Gradient Overuse**: Are buttons and headers using solid, deliberate colors instead of purple-to-cyan mesh gradients?
3. [ ] **Space Efficiency**: Does the user see the maximum amount of relevant data with minimum scrolling?
4. [ ] **No Cliché Icons**: Are sparkles, flames, and rocket icons removed unless explicitly indicating an emergency/priority?
5. [ ] **Clean Alignment**: Are labels, inputs, table columns, and totals aligned cleanly along consistent grid lines?
6. [ ] **Accessible Contrast**: Do all text elements pass WCAG AA contrast (minimum 4.5:1 for body and labels)?
